RESONIX 2026 — Local Website

QUICK START
1. Extract this ZIP completely.
2. Open the RESONIX-2026 folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
No Node.js, npm, or build step is required.

OPTIONAL: VS CODE
Open the extracted folder in VS Code. With the Live Server extension installed,
right-click index.html and choose Open with Live Server.

OPTIONAL: PYTHON
Open a terminal inside the extracted folder and run:
python -m http.server 8000
Then visit http://localhost:8000
Press Ctrl+C in the terminal to stop the server.

FILES TO EDIT
index.html  — Page sections, college details, contact details, and form fields.
style.css   — Red/orange theme, typography, spacing, and responsive layouts.
data.js     — All 11 events, dates, times, fees, rules, coordinators, and FAQs.
app.js      — Tabs, search, countdown, dialogs, gallery, and form validation.
assets/     — All included photos and hero artwork.
photo-sources.json — Photo credits, source links, and license references.

NOTES
This is a front-end demo. The registration form validates entries but does not
save or send them. The optional file input does not upload files. There is no
payment processing or backend. Contact numbers, coordinator profiles, college
information, event fees, and schedules are illustrative placeholders.

All page images are included. Google Fonts require internet access; if offline,
the page uses system fonts. The rest of the static site can run offline.
The hero artwork is an original generated circuit-hero illustration.
Demo photographs are illustrative stock images, not actual RESONIX event photos.
